Getting started

Up and writing in a few minutes.

  1. Download Hush WriterOn Windows, get hush-writer.exe from the button above. No installer is needed. Put it anywhere and double-click to run. On a Mac, download the zip, double-click it to unzip, and drag Hush Writer into your Applications folder.
  2. Set up an AI providerFor private, local AI, set up Ollama (see Setting up Ollama below). Or open Settings in Hush Writer and add an OpenAI or Anthropic API key.
  3. Start writingType away. When you want help, select some text and pick a suggestion, or press Enter at the end of a line.
Seeing “Windows protected your PC”?

Hush Writer isn't code-signed yet, so Windows SmartScreen may warn you the first time you run it. Click More info, then Run anyway.

Mac says Hush Writer “can't be opened”?

Hush Writer isn't signed by Apple yet, so macOS blocks it the first time. Click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway next to Hush Writer. You only need to do this once.

Setting up Ollama

Ollama runs AI models on your own computer, so your writing never leaves it. It's free and takes about 15 minutes to set up, most of which is waiting for the download.

  1. Download OllamaGo to ollama.com/download, choose Windows or macOS and download it.
  2. Install itOn Windows, run the installer and follow the prompts. On a Mac, unzip it and drag Ollama into Applications, then open it. Ollama then runs in the background, with a llama icon in the system tray near the clock (Windows) or the menu bar at the top of the screen (Mac).
  3. Open a terminalOn Windows, press the Windows key, type PowerShell and press Enter. On a Mac, press Cmd+Space, type Terminal and press Enter.
  4. Download the AI modelType this command and press Enter. The model is about 2 GB, so this may take a few minutes. 
    ollama pull qwen2.5:3b
  5. Start Hush WriterThat's it. Hush Writer already uses Ollama's standard address (http://localhost:11434) and the qwen2.5:3b model, so there's nothing to change in Settings.
What kind of computer do I need?

For the default model, at least 8 GB of memory and about 3 GB of free disk space. A graphics card makes suggestions much faster, but isn't required.

Choosing a different model

The default, qwen2.5:3b, is a good balance of speed and quality on most computers. Bigger models write better but need more memory and respond more slowly; smaller ones are quicker but make more mistakes. Pick one that fits your computer, download it with ollama pull, then enter its name as the model in Hush Writer's Settings.

For example, to switch to the 7B Qwen model:

ollama pull qwen2.5:7b

Sizes are approximate and come from the Ollama model library, where you can browse many more models. You can keep several downloaded and switch between them in Settings; remove one you no longer need with ollama rm followed by its name.

Suggestions not working?
  • Make sure Ollama is running. Look for the llama icon in the system tray (Windows) or menu bar (Mac). If it isn't there, open Ollama from the Start menu or your Applications folder.
  • Check the model is downloaded. Run ollama list in PowerShell or Terminal. You should see qwen2.5:3b.
  • Using a different model? Enter its name in Hush Writer's Settings, exactly as ollama list shows it.

Frequently asked questions

Is Hush Writer free?

Yes. Hush Writer is free. Local AI through Ollama is free too; OpenAI and Anthropic charge for API use on your own account.

Does my writing get sent anywhere?

With Ollama, no. Everything stays on your computer. If you choose a cloud provider, the text you ask it to improve is sent to that provider.

Where are my API keys stored?

On your computer only, in the app's local settings. They are sent only to the provider you chose.

Which port does Ollama use, and how do I check it?

Ollama uses port 11434 unless you've changed it, and Hush Writer connects to http://localhost:11434 by default, so most people don't need to do anything.

To check, open http://localhost:11434 in your browser. If it says “Ollama is running”, you're all set. If the page doesn't load, make sure Ollama is running, then run this in PowerShell:

echo $env:OLLAMA_HOST

or this in Terminal on a Mac:

echo $OLLAMA_HOST

If nothing is printed, Ollama is on the default port. If you see an address such as 0.0.0.0:8080, open Settings in Hush Writer and set Ollama host to http://localhost:8080, using the port number shown.

What do I need to run it?

On Windows: Windows 10 or 11 with Microsoft's WebView2 runtime, which comes with Windows on almost all machines. On a Mac: a recent version of macOS, on an Intel or Apple Silicon Mac.

Is there a Linux version?

Not yet as a download, but the app can be built from the source code.
