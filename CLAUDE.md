# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

"Write" — a desktop writing app built with **Wails v2** (Go backend + React/Vite frontend). The user writes in a TinyMCE rich-text editor; an "Improve" panel sends the plain text to a **local Ollama** server and shows the rewritten result. The Go module and binary are named `chromebox` (see `go.mod`, `wails.json`), though the window title is "Write".

## Commands

Run from the repo root unless noted (requires the Wails CLI, Go 1.26, Node):

- `wails dev` — run the app with hot reload (starts Vite via `npm run dev`; also serves a browser dev URL with Go bindings).
- `wails build` — production build; output goes to `build/bin/`.
- `wails generate module` — regenerate `frontend/wailsjs/` bindings after changing exported methods on `App`.
- `cd frontend && npm install` — installs deps; its `postinstall` script (`scripts/copyTinymce.mjs`) copies `node_modules/tinymce` into `public/tinymce`. If the editor fails to load, rerun this.
- `cd frontend && npm run build` — frontend-only build into `frontend/dist`.

There are no tests or linters configured.

## Architecture

- **`main.go`** — configures the Wails window, embeds `frontend/dist` via `//go:embed`, and binds the `App` struct so its exported methods are callable from JS. `frontend/dist` must exist for `go build` to compile.
- **`app.go`** — all backend logic:
  - `startup` resizes/centers the window to 90% of the primary screen.
  - `ImproveText(text, host, model, prompt)` POSTs to `{host}/api/generate` (non-streaming) and returns the trimmed response. Empty args fall back to the `default*` constants.
  - `GetDefaultOllamaSettings()` exposes those defaults so the frontend doesn't duplicate them — the Go constants are the single source of truth.
- **`frontend/wailsjs/`** — auto-generated by Wails; don't edit by hand. The frontend imports Go methods from `../wailsjs/go/main/App`.
- **`frontend/src/App.jsx`** — the whole UI: TinyMCE editor (self-hosted, loaded from `/tinymce/tinymce.min.js`, `licenseKey="gpl"`) on the left; a side panel with Improve and Settings tabs. Settings (host/model/prompt) persist in `localStorage` under `ollamaSettings`; the Improve tab reads them at call time and passes them to `ImproveText`. Text is sent as plain text (`getContent({ format: 'text' })`), so formatting is not preserved through the improve round-trip.
